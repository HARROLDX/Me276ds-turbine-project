01 / 项目出发点与计划
Motivation and study design

燃气轮机 NOₓ 排放预测。面向电厂运行人员与环境监测工程师，用已有环境和运行读数估计同期排放，辅助监测交叉核验与异常排查。模型不是排放仪器的替代品，也不能从预测关系推断控制措施的因果效果。

Gas turbine NOₓ prediction. We use existing ambient and operating readings to estimate contemporaneous emissions for operators and monitoring engineers. The model supports cross-checking and diagnosis; it does not replace emission instruments or establish causal control effects.

数据：UCI Gas Turbine CO and NOx Emission Data Set，土耳其西北部一座电厂，2011–2015 年，共 36,733 条小时聚合记录。输入为 AT、AP、AH、AFDP、GTEP、TIT、TAT、TEY、CDP；目标为 NOX（mg/m³）。CO、年份和行号不作为输入。

Data: UCI Gas Turbine CO and NOx Emission Data Set, one plant in northwestern Turkey, 2011–2015, with 36,733 hourly aggregated records. Nine ambient and operating variables are inputs; NOX (mg/m³) is the target. CO, year and row identifiers are excluded.

训练：2011–2014 年及 2015 年按原始记录顺序的前半段，共 33,041 条；测试：2015 后半段 3,692 条。数据无精确时间戳，“前后半段”不是按 6 月 30 日切分。本轮无独立验证集，沿用历史已定参数；历史选择曾用到现已并入训练的 2015 前半段。

Training uses 33,041 rows from 2011–2014 and the first half of ordered 2015 records. Testing uses the remaining 3,692 rows. Exact timestamps are unavailable, so halves refer to row order, not a June 30 boundary. Settings were fixed from earlier selection; the former selection period is now included in training.

计划：统一数据与指标比较四类模型，分析误差，再以 MLP 为基线研究输入特征和正则化。本次汇报截至四模型比较，不展示拓展实验结果。

Plan: compare four model families under one protocol, analyze errors, then investigate input selection and regularization using MLP. This briefing reports the four-model comparison only.

02 / 四种方法如何设计
Four model designs

线性回归：ŷ = b + Σ wⱼxⱼ。最小化训练残差平方和，得到全局线性映射。它易解释、适合作为基线，但不能直接表示温度、压力和负载之间的非线性交互。

Linear regression: ŷ = b + Σ wⱼxⱼ. Ordinary least squares minimizes squared training residuals. It is interpretable, but a single linear mapping cannot directly express nonlinear interactions among temperature, pressure and load.

随机森林：ŷ = (1/B)Σ Tᵦ(x)。200 棵自助采样回归树，最大深度 12，叶节点至少 1 个样本；平均树预测降低方差，并表达非线性与交互。树的分段常数预测对未覆盖工况的外推有限。

Random forest averages 200 bootstrap regression trees, with maximum depth 12 and minimum leaf size 1. Averaging reduces variance while trees capture nonlinearities and interactions. Piecewise-constant predictions have limited extrapolation to unseen operating regions.

梯度提升：Fₘ(x) = Fₘ₋₁(x) + ηhₘ(x)。使用 100 棵深度 3 的树，学习率 0.05；逐步拟合前一步的残差以降低平方误差。小步叠加控制复杂度，但固定深度和迭代数可能限制拟合能力。

Gradient boosting adds shallow trees to correct residual errors: Fₘ = Fₘ₋₁ + ηhₘ. We use 100 trees of depth 3 with learning rate 0.05. Small updates control complexity, although fixed depth and iteration count may limit fit.

MLP：ŷ = W₂ ReLU(W₁x+b₁)+b₂。9 个输入、单隐层 32 个 ReLU 单元、1 个线性输出；Adam 学习率 0.001，L2 强度 0.01，最多 500 轮。本轮在 229 轮达到训练停止条件；未使用验证集早停。

MLP uses nine inputs, one hidden layer of 32 ReLU units and one linear output. Adam learning rate is 0.001, L2 strength is 0.01, and the iteration limit is 500. This fit stopped after 229 iterations based on training convergence, not validation-based early stopping.

线性回归与 MLP 的输入标准化仅拟合训练集；MLP 的目标也按训练集标准化，预测再还原为 mg/m³。随机种子固定为 276。

Input standardization for OLS and MLP is fitted only on training rows. MLP also standardizes the training target and converts predictions back to mg/m³. The random seed is 276.

Results and the MLP advantage

这里比较的是三个评价指标，不是三个模型参数。MAE = mean(|y−ŷ|)，RMSE = √mean((y−ŷ)²)，R² = 1−Σ(y−ŷ)²/Σ(y−ȳtest)²。MAE 与 RMSE 的单位均为 mg/m³。

These are three evaluation metrics, not model parameters. MAE is mean absolute error; RMSE is root mean squared error; R² compares squared error against the test-mean reference. MAE and RMSE are measured in mg/m³.

观察到的事实：MLP 的 MAE 和 RMSE 最低，R² 最高。相较线性回归，MAE 降低约 25.4%，RMSE 降低约 19.4%。在同一测试集上，R² 与 RMSE 都由残差平方和决定，因此两者排名相同，不是两份独立证据。

Observed: MLP has the lowest MAE and RMSE and the highest R². Relative to OLS, MAE falls by about 25.4% and RMSE by 19.4%. On one fixed test set, RMSE and R² are both functions of squared error, so their matching rankings are not independent evidence.

可能解释：排放与温度、压力、负载之间可能存在非线性交互，MLP 的隐层比单一线性映射更灵活；与分段常数的树模型相比，ReLU 网络可表达连续的分段线性响应。输入与目标标准化改善优化尺度，适度 L2 惩罚可能限制过大的权重。

Possible explanations: hidden units can represent nonlinear interactions among operating variables; a ReLU network also provides continuous piecewise-linear responses, unlike piecewise-constant trees. Input and target scaling improve optimization conditioning, and L2 may restrain large weights.

这些是机制上合理的解释，并非已证实的原因。当前只有固定配置和单一种子，没有置信区间或独立验证；不能断言神经网络普遍优于森林，或已证明正则化导致优势。

These mechanisms are plausible, not established causes. A single seed and fixed configurations, without uncertainty intervals or independent validation, cannot establish universal MLP superiority or a causal benefit from regularization.

04 / 为什么 R² 仍不高？
Why is R² modest or negative?

本测试集目标标准差约 8.717 mg/m³。始终预测测试均值的参照 RMSE 就是这个标准差；MLP 的 RMSE 为 8.070，只略低于该参照。R² = 0.143 表示相对参照减少约 14.3% 的平方误差，不能解释成“准确率 14.3%”。

The target standard deviation on this test set is about 8.717 mg/m³, equal to the RMSE of the constant test-mean reference. MLP RMSE is 8.070, only moderately lower. R² = 0.143 means a 14.3% reduction in squared error against that reference, not 14.3% accuracy.

其他三种模型的 RMSE 约 10.01–10.15，高于参照，因此 R² 为负。负数表示残差平方和大于测试集围绕其均值的总平方和，不代表相关系数为负或预测方向全部相反。测试均值参照使用了真实测试标签，是解释性基准，不是可部署预测器。

The other three models have RMSE around 10.01–10.15, above the reference, yielding negative R². This means squared prediction error exceeds variation around the test mean; it does not imply negative correlation or uniformly reversed predictions. The test-mean reference uses test labels and is interpretive, not deployable.

为什么会这样：按时间划分要求模型适应较晚工况；运行条件或传感器关系随时间变化，可能造成分布漂移。九个观测变量也未必完整刻画燃烧状态，噪声和未观测因素可能限制精度。固定参数可能对当前训练窗口并非最优。以上属于待检验解释，不能仅凭这张指标表认定发生了漂移或找出具体缺失机制。

Possible reasons include temporal changes in operating conditions or sensor relationships, incomplete measurement of combustion state, noise, and settings that are not optimal for the current window. These remain hypotheses: the score table alone cannot establish distribution shift or identify missing mechanisms.

下一步诊断：比较训练与测试的输入及目标分布；按负载与温度区间检查残差；区分整体偏置和局部大误差。由于测试结果已被多次查看，后续结论应标注探索性，最终泛化需要新时间段数据验证。

Next diagnostics: compare train/test input and target distributions, examine residuals by load and temperature, and separate systematic bias from local large errors. Repeated inspection makes further conclusions exploratory; future time periods are needed for independent confirmation.

05 / 接下来的研究计划
Next research tasks

拓展实验一：输入特征选择。以九输入 MLP 为基线，固定网络、正则化和训练条件，比较减少输入后的误差与传感器需求。先检验已有八输入组合（省去 CDP），明确它来自此前线性模型的选择，而不是 MLP 的最优子集。

Extension 1: input selection. Keep architecture, regularization and training conditions fixed while comparing a nine-input MLP with fewer inputs. Start with the existing eight-input subset excluding CDP, acknowledging that it was selected for a linear model, not optimized for MLP.

拓展实验二：正则化。保持输入和网络结构不变，比较预先指定的 L2 强度（0、0.01、0.1），考察约束复杂度是否改善误差。不能依据同一测试集挑选强度后，再把该测试分数当作独立证明。

Extension 2: regularization. Keep inputs and architecture fixed and compare prespecified L2 strengths of 0, 0.01 and 0.1. Examine whether complexity control improves errors. Selecting a strength using this same test set would not provide independent validation.

本次汇报仅介绍这两个后续研究方向，不汇报其结果。网站可能已包含探索性拓展记录；本报告有意限定在四模型主实验与后续计划。

This briefing introduces these two next research directions without reporting their outcomes. The website may already contain exploratory extension records; this report intentionally limits its scope to the main comparison and next steps.
